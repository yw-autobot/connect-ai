# Antigravity Curated Skills

Use these upstream skills as reference patterns when Developer is building, debugging, testing, or creating tools.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `senior-frontend` - React, Next.js, TypeScript, Tailwind, performance, accessibility, and frontend quality.
- `react-best-practices` - React/Next.js implementation and review rules.
- `mcp-tool-developer` - building MCP servers and tools in TypeScript or Python.
- `mcp-builder-ms` - integrating external APIs and services through MCP-style tools.
- `acceptance-orchestrator` - driving coding tasks from issue intake through implementation, review, and verification.
- `github-automation` - GitHub workflow automation. Treat as high-risk guidance unless credentials and approval gates are configured.

## Operating Rule

Developer can use safe implementation skills directly as design patterns. Skills involving publishing, repository automation, deployment, credentials, or external API mutation should stay in draft/approval mode.
