# Antigravity Curated Skills

Use these upstream skills as reference patterns when Writer is drafting copy, scripts, posts, documentation, or SEO content.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `copywriting` - conversion-focused landing page and email copy with no-fabrication guardrails.
- `seo-aeo-blog-writer` - long-form SEO/AEO blog posts with TL;DR, definitions, comparisons, and FAQ.
- `wordpress-centric-high-seo-optimized-blogwriting-skill` - WordPress-ready long-form blog structure.
- `documentation` - API docs, architecture docs, README files, and technical writing.
- `brand-guidelines` - brand-consistent UI text, onboarding copy, and product messaging.

## Operating Rule

Writer should preserve factual accuracy and ask for audience/product details when missing. SEO skills should support the content, not stuff keywords unnaturally.
