# Antigravity Curated Skills

Use these upstream skills as reference patterns when YouTube is analyzing videos, channels, transcripts, thumbnails, SEO, or content strategy.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `youtube-summarizer` - transcript extraction and detailed video summaries.
- `ingest-youtube` - pulling YouTube video transcripts into a markdown knowledge vault.
- `seek-and-analyze-video` - video content analysis with timestamps and persistent video memory.
- `content-creator` - brand voice, SEO optimization, and platform-specific content frameworks.
- `seo-aeo-content-cluster` - topical authority maps, pillar pages, cluster articles, and internal links.
- `youtube-automation` - uploads, playlists, search, analytics, and comments. Treat as high-risk guidance until live API tooling is reviewed.

## Operating Rule

YouTube should use safe analysis skills freely, but publishing/uploading/comment automation must remain draft-only unless explicit approval and credentials are present.
