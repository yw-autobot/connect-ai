# Antigravity Curated Skills

Use these upstream skills as reference patterns when Researcher is gathering evidence, scraping data, monitoring trends, or synthesizing reports.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `deep-research` - autonomous research planning, search, reading, and synthesis.
- `web-scraper` - structured web extraction from pages, lists, tables, prices, and paginated sources.
- `wiki-researcher` - deep "how does this work" technical/system analysis.
- `tavily-web` - web search, extraction, crawling, and research using Tavily-style APIs.
- `xvary-stock-research` - thesis-driven equity analysis from public filings and market data.

## Operating Rule

Researcher should cite sources, distinguish facts from inference, and avoid using scraping or paid APIs unless credentials and user approval are available.
