# Antigravity Curated Skills

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `007` - security audit, hardening, threat modeling, OWASP checks, incident response, and infrastructure security. Use defensively only.
- `api-security-best-practices` - API security design and review.
- `agentic-actions-auditor` - audits GitHub Actions workflows for AI agent integration risks.
- `active-directory-attacks` - high-risk reference. Defensive detection and hardening only.
- `malware-analyst` - high-risk reference. Defensive malware research only.
- `api-fuzzing-bug-bounty` - high-risk reference. Only use in owned systems with explicit authorization.

## Operating Rule

Skills marked offensive, critical, or attack-oriented are blocked from direct execution. Use them only to build defensive checklists, threat models, and remediation plans.
