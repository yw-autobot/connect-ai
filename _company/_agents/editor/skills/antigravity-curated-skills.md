# Antigravity Curated Skills

Use these upstream skills as reference patterns when Editor is handling audio, video, transcription, subtitles, music, or media workflows.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `videodb` - video/audio perception, indexing, searching, timeline edits, subtitles, overlays, and alerts.
- `videodb-skills` - VideoDB SDK workflows for upload, stream, search, edit, transcribe, and generate.
- `audio-transcriber` - transforming audio recordings into structured markdown notes and summaries.
- `remotion-best-practices` - React-based video creation patterns.
- `game-audio` - sound design, music integration, and adaptive audio systems.
- `voice-ai-development` - real-time voice agents and voice-enabled app patterns.

## Operating Rule

Editor should use these as creative and technical workflow references. Media generation or external upload APIs need configured tools and approval.
