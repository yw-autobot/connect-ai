**목적:** 영상 스크립트의 감정선(Pain $\rightarrow$ Solution)을 시각적으로 강제하여, 콘텐츠를 '정보 전달'이 아닌 '문제 해결 시스템 제안'으로 인식하게 한다.
**주요 컴포넌트:** Pain Hook Box (경고), Knowledge Fragmentation Map (혼란), System Funnel Diagram (구조화).

---

#### Ⅰ. 🚨 Pain Point Hook Component (Warning / 충격)

| 규정 요소 | 스펙 상세 | 적용 방식 | 시각적 효과 |
| :--- | :--- | :--- | :--- |
| **색상 코드** | 배경: `#FF5722` (Pain Orange-Red). 텍스트/아이콘: 흰색 (`#FFFFFF`). | 영상 시작 0초~5초, 또는 핵심 문제 제기 시. | 충격적, 즉각적인 주의 환기(Attention Grab). |
| **배치 원칙** | 화면의 좌측 상단 (시선이 가장 먼저 머무는 곳)에 고정 배치. | 가로 비율 3:1 정도의 강렬한 박스 형태. | '경고' 메시지를 공간적으로 압도하며, 시청자에게 위기감을 주입. |
| **텍스트 구조** | `[⚠️ 충격적인 질문]` + (작은 글씨) `당신의 현 상황 진단 결과:` | 폰트 크기는 최소화하고, 문구 자체를 충격적이고 단정적으로 작성. 예: "이대로는 돈 못 벌어요." | 감정적 공감 유도와 함께 즉각적인 문제 인식 강제. |
| **아이콘 활용** | `🚨`, `❌` 등 단순하고 굵은 이모지/벡터 아이콘을 필수적으로 사용. | Pain Point의 상징성 강화. |

#### Ⅱ. 🧩 Knowledge Fragmentation Map Component (혼란 / 비체계)

| 규정 요소 | 스펙 상세 | 적용 방식 | 시각적 효과 |
| :--- | :--- | :--- | :--- |
| **배경 컨셉** | '파편화(Fragmented)'된 느낌. 겹치고, 뒤섞이고, 연결되지 않은 이미지들의 콜라주 구조. | Pain Point가 최고조에 달했을 때 (0:10~0:20 구간). | 시각적 노이즈와 혼란을 극대화하여, 현재의 방식이 '비효율적'임을 강조. |
| **요소 구성** | 수기 노트 스크랩 이미지, 복잡한 화살표(무작위 방향), 겹쳐진 PDF 아이콘 등. | 다양한 자료들이 무질서하게 움직이는 애니메이션 효과를 적용. | 지식의 '양'은 많지만, '구조'가 없음을 직관적으로 전달. |
| **강조 메시지** | 모든 파편화된 정보 위에 `[오류(ERROR)]` 또는 `[미연결]` 워터마크를 겹치게 배치. | 구조적 결함을 시각적으로 지적함. |

#### Ⅲ. 🚀 System Funnel Diagram Component (구조화 / 해결책)

| 규정 요소 | 스펙 상세 | 적용 방식 | 시각적 효과 |
| :--- | :--- | :--- | :--- |
| **색상 코드** | 주 흐름: `#4CAF50` (Solution Emerald Green). 단계 구분선: 다크 그레이 (`#1A1A1A`). | Solution 제시 단계 (0:20 이후)부터 끝까지. | 성장, 명확성, 안정감(Trust)을 부여하며 시청자의 기대감을 해소함. |
| **구조 원칙** | **[단계 1] $\rightarrow$ [프로세스 핵심 로직] $\rightarrow$ [최종 결과/수익화]**의 단방향 흐름을 강제. | '사다리'나 '깔때기(Funnel)' 모양으로 계단식 레이아웃을 사용. | 복잡한 문제가 단순하고 체계적인 과정으로 해결됨을 직관적으로 증명. (가장 중요한 판매 논리) |
| **핵심 요소** | 각 단계별로 명확한 *입력*, *변환 로직(화살표)*, *출력* 박스를 할당. `[자동화]`, `[시스템]` 등의 키워드를 `#4CAF50`으로 강조. | 과정 자체를 상품처럼 보여줌으로써, '정보'가 아닌 '방법론'을 판매함을 암시. |

### 🖼️ 썸네일 구성 요소별 상세 디자인 스펙

#### 1. 배경 및 분위기 (Base Layer)
*   **톤:** 어두운 무광 다크 그레이 (`#1A1A1A`)를 사용하여 전문성과 무게감을 부여합니다. [근거: Designer 검증된 지식]
*   **전반적 느낌:** 복잡한 비즈니스 문제 앞에서 방황하는 듯하지만, 해결의 실마리가 보이는 구도.

#### 2. 좌측 상단: Pain Point Hook (경고) - (최대 시각적 무게)**
*   **배치:** 화면 전체에서 가장 눈에 띄는 위치.
*   **디자인:** `#FF5722` 배경의 강렬한 박스. 경계선을 두껍게 처리하여 분리감을 극대화합니다.
*   **카피 (Mock):** "❌ 당신은 '노력'만 하고 있습니다." (가장 큰 폰트)
*   **서브 카피:** "(Feat. 시스템적 사고의 부재)" (작지만 위기감을 조성하는 문구).

#### 3. 중앙: Value Proposition & Flow Diagram (시스템 증명)**
*   **핵심 이미지:** '흩어진 지식(Fragmented Knowledge)' 이미지를 배경에 흐릿하게 배치하고, 그 위에 **System Funnel Diagram 컴포넌트**를 오버레이합니다.
*   **Flowchart 디자인:**
    1.  (Pain) $\rightarrow$ (변환 과정: 시스템 구축) $\rightarrow$ (Solution)의 단계를 명확한 `#4CAF50` 화살표와 박스로 연결합니다.
    2.  **강조 요소:** '시스템화'라는 키워드는 굵고, 빛이 나는 듯한 질감(Glow effect)을 주어 시선을 집중시킵니다.
*   **주요 타이틀 (Mock):** "노하우 $\rightarrow$ 시스템 판매 구조로 전환하는 법"

#### 4. 우측 하단: CTA 및 상품 제시 (구매 논리)**
*   **레이아웃:** 마치 컨설팅 보고서의 '결론' 페이지처럼 간결하고 명확하게 분리합니다.
*   **상품 박스 예시:** **[Core Pack]** - 3단계 Funnel Blueprint 포함 / 가격 대비 효과 강조 (가격 대신 가치로 승부).
*   **CTA 문구:** "🔥 더 자세한 구조는 영상에서 확인하세요." (직접적이고 명령조의 문구)
