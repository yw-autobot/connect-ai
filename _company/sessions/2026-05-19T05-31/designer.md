### B. 타이포그래피 규칙 (Typography Rules)
*   **폰트 선택:** Pretendard (가장 가독성이 높고 시스템적인 느낌을 줌.)
*   **제목/핵심 메시지 (H1):** Bold, 72pt 이상. 흰색 또는 `#4CAF50` 사용. (최대 시각적 무게 담당)
    *   *규칙:* 최대 8자 이내의 짧고 강력한 구문만 사용한다.
*   **보조 설명/Pain Point (H2):** SemiBold, 36pt. `#FF5722` 배경에 흰색으로 대비시킨다.
*   **판매 구조/데이터 (Body):** Medium, 24~30pt. 흰색 또는 밝은 회색 사용.

## Ⅱ. Funnel 단계별 레이아웃 시스템 (Layout Modules)

모든 썸네일은 **(Pain Point Hook $\rightarrow$ Value Proposition $\rightarrow$ CTA)**의 3단 구조를 유지하되, 각 캠페인 단계의 목적에 맞게 강도를 조절한다.

### 🧩 Module A: 인지 단계 (Awareness Stage - Pain Recognition)
*   **목적**: "나에게 문제가 있다"는 공감대를 형성하고 충격으로 끌어당긴다.
*   **레이아웃 특징**: **Pain Point Hook을 좌측 상단에 가장 크게 배치.** Value Proposition은 모호한 질문 형태로 제시한다.
    *   **배치 비율:** Pain (40%) : Question (35%) : CTA (25%)
    *   **강조 방식:** 문제점(Pain)의 크기/색상을 최대화하여 시선 강탈을 최우선으로 한다.

### 🧩 Module B: 관심 단계 (Interest Stage - Solution Mapping)
*   **목적**: "문제를 해결할 수 있는 방법이 있구나"라는 기대감을 심어준다.
*   **레이아웃 특징**: **Value Proposition(워크플로우/시스템 다이어그램)을 중앙에 배치.** A에서 던진 질문에 대한 '체계적인 해답'의 힌트를 시각화한다.
    *   **배치 비율:** Pain (20%) : System Flow (55%) : CTA (25%)
    *   **강조 방식:** `#4CAF50` 강조색을 사용하여 A $\rightarrow$ B $\rightarrow$ C와 같은 **흐름(Flow)**에 초점을 맞춘다.

### 🧩 Module C: 구매 고려 단계 (Decision Stage - Product Hook)
*   **목적**: "이것으로 끝내자"라는 즉각적인 행동 유도와 명확한 가치를 제시한다.
*   **레이아웃 특징**: **Pricing/Product Grid를 좌측 하단에 가장 크게 배치.** 전체 화면의 절반 이상을 '구매해야 할 상품'처럼 보이게 만든다.
    *   **배치 비율:** Pain (15%) : System Flow (30%) : Product (55%)
    *   **강조 방식:** 가격표/비교표 형태로 **대비(Contrast)**를 극대화하고, 핵심 가치를 가진 상품만 `#4CAF50`으로 빛나게 처리한다.
