# Antigravity Curated Skills

Use these upstream skills as reference patterns when CEO is coordinating strategy, routing work, or improving the agent company.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `agent-orchestrator` - multi-agent coordination, skill registry scanning, and workflow routing.
- `antigravity-skill-orchestrator` - deciding when specialist skills are worth using and preventing overuse.
- `architecture` - architectural decision-making, trade-off analysis, and ADR-style reasoning.
- `blueprint` - turning a vague objective into an execution plan that another agent can follow.
- `agent-evaluation` - evaluating agent behavior, capability, reliability, and production readiness.

## Operating Rule

CEO should use these as planning and routing references, not as direct execution tools. If a task becomes implementation-heavy, dispatch it to the matching specialist.
