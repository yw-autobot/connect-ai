# Antigravity Curated Skills

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `github-automation` - GitHub issues, PRs, CI/CD, and repository workflow automation. Treat write actions as gated.
- `agentic-actions-auditor` - GitHub Actions security review for agent workflows.
- `docker` / cloud and devops category skills - container and deployment patterns.
- `acceptance-orchestrator` - end-to-end issue through deployment workflow.
- `reliability` category skills - production readiness and operational checks.

## Operating Rule

Use upstream skills to draft release plans and diagnostics. Production deploys, infra mutation, DNS changes, and secret updates require explicit approval.
