### 📝 1. 핵심 기획안 (Storyline & Mechanic)

#### **게임 제목**: `Sky Protocol` (공격형 비행기 게임)

| 요소 | 상세 |
|------|------|
| **장르** | Roguelike + Hyper-Casual 하이브리드 |
| **타깃** | 20~40대 남성 / 투자자 / 창업가 (Pain-Triggered Audience) |
| **Core Mechanic** | "Air Traffic Controller" → 플레이어는 비행기를 조종하지만, **실제 비즈니스 흐름(Workflow)** 을 최적화하는 전략적 요소가 통합됨 |
| **Storyline** | - 주인공: 실패한 투자자 (초반) <br> - 목표: 300만원 달성 (월 목표와 동일 프레임) <br> - 갈등: "노력"이 부족하지 않음, **시스템(Workflow)** 이 깨짐 <br> - 해결: `Sky Protocol` 게임 → 비즈니스 워크플로우 최적화 |
| **유니크 Selling Point** | **게임 플레이 = 비즈니스 워크플로우 시뮬레이션** |

### 📝 2. 후킹 스크립트 초안 (Hook Script)

#### **A안**: Pain Focus (Pain Triggered)
```markdown
[0:00 - 0:30] 
"당신이 실패한 건 노력이 부족해서가 아닙니다. 
'비행기'는 당신에게 날아오르도록 설계된 게 아닙니다. 
시스템이 당신을 아래로 밀고 있습니다."

[심리 상태 유도]
🚨 공감/충격 (Pain Trigger) → "비즈니스 실패"와 직접 연결
```

#### **B안**: Contradiction Focus (Contrarian Warning)
```markdown
[0:00 - 0:30] 
"월 300만원 버는 비밀? 다들 아는 방법은 함정입니다. 
진짜 핵심은 이것 — '비행기'를 조종하는 법을 모르는 것입니다."

[심리 상태 유도]
💥 반전/충격 (Contradiction) → "함정"과 "비밀" 키워드 사용
```

#### **C안**: Result Focus (Outcome Driven)
```markdown
[0:00 - 0:30] 
"단 1주일 만에 콘텐츠로 돈 버는 시스템. 
제가 처음부터 끝까지 설계해 드립니다 — 비행기 게임처럼."

[심리 상태 유도]
🎯 기대감/신뢰 (Result Promise) → "시스템"과 "설계" 키워드 사용
```

### 📝 3. 핵심 메커니즘 (Core Mechanic)

#### **게임플레이 흐름**
| 단계 | 게임 행동 | 비즈니스 연결 |
|------|-----------|--------------|
| **1. Takeoff** | 비행기 이륙 → 초기 투자금 확보 | "초기 자본" 필요성 인식 |
| **2. Navigation** | 풍향/비행고도 최적화 → 워크플로우 설계 | "시스템(Workflow)"이 중요함 |
| **3. Storm** | 폭풍 통과 → 위기 관리 | "위기 상황 대응" 훈련 |
| **4. Landing** | 안전한 착륙 → 월 300만원 달성 | "목표 달성" 확인 |

#### **수익화 연결**
- **IAP**: `Sky Protocol Pro` (워크플로우 최적화 도구)
- **Ads**: 광고 중 게임 내 비즈니스 성공 사례 제시
- **Funnel**: 게임 완료 후 → 랜딩 페이지 전환 (CRA, CTA 버튼)
