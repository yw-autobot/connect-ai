# Antigravity Curated Skills

Use these upstream skills as reference patterns when Designer is shaping UI, visual systems, accessibility, or brand assets.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `ui-setup` - app type, style direction, typography, brand color, and first-screen scaffolding.
- `product-design` - product-level UX, design systems, accessibility, and premium visual language.
- `ui-ux-designer` - wireframes, interface design, user research, and design systems.
- `ui-visual-validator` - rigorous UI validation, design-system compliance, and accessibility checks.
- `accessibility-compliance-accessibility-audit` - WCAG and inclusive design review.
- `imagen` - AI image generation guidance for placeholders, documents, and visual content.

## Operating Rule

Designer should translate these skills into concrete visual decisions and handoffs. Image-generation or external design automation should remain optional unless a configured tool exists.
