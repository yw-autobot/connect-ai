# Antigravity Curated Skills

Use these upstream skills as reference patterns when Instagram is planning posts, captions, growth experiments, creative testing, or social distribution.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `social-post-writer-seo` - Instagram, LinkedIn, and Facebook post writing with platform-specific nuance.
- `social-content` - multi-platform social strategy and scheduling-oriented content planning.
- `instagram` - Instagram Graph API publishing, analytics, comments, DMs, hashtags, and scheduling. Treat as high-risk guidance.
- `screenshots` - Playwright-based marketing screenshots for product launches.
- `xiaohongshu-content-strategist` - platform-native short-form content strategy patterns that can inspire Instagram creative.

## Operating Rule

Instagram should separate strategy/copy from live posting. Any publishing, DM, or comment automation needs approval and configured credentials.
