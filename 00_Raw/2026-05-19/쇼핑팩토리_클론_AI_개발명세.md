# 쇼핑팩토리 유사 수익화 사이트 클론 개발 명세

작성일: 2026-05-19  
분석 대상: https://shopping.tubefactory.kr/  
목적: AI 개발 에이전트가 "레퍼런스 영상 기반 쇼핑 숏폼 자동 제작 SaaS"를 만들 수 있도록 필요한 기능, 지식, 기술 스택, 구현 범위, 데이터 모델, 운영 체크리스트를 정리한다.

> 주의: 이 문서는 타 사이트의 브랜드, 문구, 이미지, 소스코드를 그대로 복제하기 위한 문서가 아니다. 합법적으로 유사한 수익화 구조와 기능을 독자 브랜드/디자인/코드로 구현하기 위한 제품 명세다.

## 1. 접근 및 분석 상태

현재 Codex 인앱 브라우저에서는 사용자의 Chrome 로그인 세션이 공유되지 않아 로그인 이후 내부 화면은 직접 확인하지 못했다. 접근 가능한 공개 화면, 리다이렉트, Next.js 번들 단서, 인증 API 응답을 기준으로 분석했다.

확인된 사항:

- 사이트명/타이틀: `쇼핑쇼츠자동제작 - 쇼핑팩토리`
- 메타 설명: `레퍼런스 영상 하나로 쇼핑쇼츠를 자동 생성합니다`
- 루트 `/`는 비로그인 상태에서 `/login?callbackUrl=%2F`로 307 리다이렉트된다.
- `/dashboard`, `/studio`, `/projects`, `/videos`, `/create`, `/generator`, `/membership`, `/pricing`, `/admin`, `/terms`, `/privacy`도 비로그인 상태에서 로그인으로 리다이렉트된다.
- 로그인 방식은 NextAuth 기반으로 보인다.
- 인증 제공자:
  - Google OAuth: `/api/auth/signin/google`
  - Credentials 로그인: `/api/auth/signin/credentials`
- 로그인 화면에는 Google 로그인과 일반 아이디/이메일 + 비밀번호 로그인이 있다.
- 멤버십 가입자는 가입한 아이디의 Google 로그인으로 진행하라는 안내가 있다.
- 사업자/푸터 정보가 로그인 화면 하단에 노출된다.

확인된 로그인 화면 구성:

- 브랜드: `Shopping Factory`
- 페이지 제목: `로그인`
- 안내 문구: `멤버십은 가입한 아이디의 구글 로그인으로 진행해주세요`
- CTA: `Google 계정으로 로그인`
- 구분 텍스트: `또는 일반 로그인`
- 입력 필드:
  - 아이디 또는 이메일
  - 비밀번호
- 일반 로그인 버튼
- 홈으로 돌아가기 링크
- 이용약관, 개인정보처리방침 링크

## 2. 제품 한 줄 정의

사용자가 상품/레퍼런스 영상을 입력하면 AI가 쇼핑 숏폼 영상 기획, 대본, 컷 구성, 자막, 음성, 편집 결과물을 자동 생성하고, 멤버십/크레딧 과금으로 수익화하는 웹 서비스.

## 3. 핵심 고객

- 스마트스토어, 쿠팡, 쇼핑몰 셀러
- 쇼핑 숏츠/릴스/틱톡 광고를 빠르게 만들고 싶은 1인 사업자
- 제휴마케팅/어필리에이트 콘텐츠 제작자
- 유튜브 쇼츠 채널 운영자
- 상품 상세페이지나 리뷰 영상을 광고 영상으로 재가공하려는 마케터

## 4. 핵심 가치 제안

- 상품 링크 또는 레퍼런스 영상 하나로 쇼핑 숏폼 자동 생성
- 광고 후킹 문구, 대본, 자막, 장면 구성 자동 생성
- 세로형 9:16 숏폼 최적화
- 여러 버전의 후킹/대본/영상 변형 생성
- 멤버십 또는 크레딧 기반으로 반복 제작 가능
- 완성 영상 다운로드 및 SNS 업로드 준비

## 11. 프론트엔드 UX 요구사항

전체 톤:

- SaaS 운영 도구 느낌
- 너무 마케팅 랜딩처럼 만들지 말고, 로그인 후 바로 작업 가능한 대시보드 중심
- 모바일에서도 생성 플로우가 가능해야 함
- 영상 제작 진행률을 명확히 보여줘야 함

컴포넌트:

- 사이드바: 대시보드, 새 영상 만들기, 프로젝트, 멤버십, 설정, 관리자
- 상단바: 사용자 프로필, 크레딧, 알림
- 생성 마법사: 입력 -> 분석 -> 대본 선택 -> 렌더링 -> 결과
- 진행 상태: 큐 대기, 분석 중, 대본 생성 중, 렌더링 중, 완료, 실패
- 결과 미리보기: 세로형 영상 프레임

필수 상태 처리:

- 로그인 필요
- 멤버십 필요
- 크레딧 부족

## 18. 로그인 후 실제 화면 분석 추가

2026-05-19에 인앱 브라우저 로그인 세션으로 내부 화면을 추가 확인했다. 사이트는 별도 URL 라우팅보다 단일 URL 안에서 좌측 메뉴/탭 상태를 바꾸는 SPA 방식에 가깝다. 클론 구현 시 라우트를 나누더라도 사용자 경험은 좌측 사이드바 + 메인 작업 영역 + 상단 포인트/계정바 구조를 유지하는 것이 좋다.

### 18.1 전체 IA / 좌측 메뉴

좌측 사이드바는 다음 그룹으로 구성되어 있다.

프로젝트:

- 프로젝트 섹션 제목
- 편집 버튼
- 접기 버튼
- 새 프로젝트 생성 한도 표시: `새 프로젝트 (1/10)`
- 기존 프로젝트 리스트 표시
- 프로젝트 상태 배지: 예시 `분석완료`
- 프로젝트명 표시
- 프로젝트 단계 표시: 예시 `단계: 영상 선택`

트렌드 리서치:

- 제품 찾기
- 실시간 쇼핑순위
- 신규 쇼핑 영상
- 추천 픽 영상

채널 & 콘텐츠:

- 내 모니터링 리스트
- 영상 스타일 분석실
- 레퍼런스 모음집

내 도구:

- 영상 다운로드
- 내 쇼핑 링크

상단바:

- 멤버십/기수 표시: 예시 `쇼팩1기`
- 포인트 잔액 표시: 예시 `9.4P`
- 충전 버튼
- 라이트/다크 모드 전환
- 새로고침 버튼
- 사용자 프로필 버튼

클론 구현 요구:

- 좌측 메뉴는 항상 유지한다.
- 현재 선택 메뉴는 active 상태로 강조한다.
- 포인트 잔액은 모든 화면에서 접근 가능해야 한다.
- 프로젝트 한도와 현재 프로젝트 수를 함께 표시한다.
- 프로젝트는 상태와 현재 단계를 함께 보여준다.

## 19. 실제 생성 플로우

홈/새 프로젝트 화면의 핵심 문구는 `레퍼런스 영상 하나로 제품 판매용 영상을 수집하고 자동 생성합니다`이다. 제작 방식은 2개가 확인된다.

- 영상 분석: 레퍼런스 영상 URL을 넣으면 대본·자막·음성을 자동 생성
- 대본 제작: 대본을 먼저 작성하고 영상을 매칭하여 숏폼 제작. 현재 준비중/비활성

영상 분석을 누르면 `레퍼런스 영상 분석` 화면으로 진입한다.

실제 단계 네비게이션:

1. 영상 분석
2. 영상 선택
3. 스크립트 & 음성
4. 스타일 설정
5. 음성 프리뷰
6. SEO
7. 내보내기

입력/액션:

- 단일 영상
- 여러 영상 믹스
- URL 입력
- 파일 업로드
- 최대 파일 크기: 500MB
- 분석 시작
- AI 영상 생성
- 설정

기본 설정 표시:

- 음성: 지영
- 속도: 1.1x
- 자유 모드
- 헤드카피 ON
- 워터마크 OFF
- 무음삭제 OFF
- BGM OFF

클론 구현 요구:

- 7단계 진행바를 만든다.
- 각 단계별 완료/현재/잠김 상태를 둔다.
- 단일 영상과 여러 영상 믹스 모드를 분리한다.
- URL 입력과 파일 업로드를 모두 지원한다.
- URL 또는 파일이 없으면 `분석 시작` 버튼을 disabled 처리한다.
- 분석 완료 전에는 `AI 영상 생성` 버튼을 disabled 처리한다.
- 설정 요약 칩을 메인 화면에 노출한다.

## 21. 트렌드 리서치 기능

### 21.1 제품 찾기

- 영상 URL 입력
- 검색
- 히스토리
- URL 검색
- 키워드 검색
- 분석

클론 구현 요구:

- `ProductSearchSession` 모델 생성
- URL 기반 제품 추정
- 키워드 기반 영상/상품 후보 검색
- 검색 히스토리 저장
- 검색 결과에서 프로젝트로 보내기 기능

### 21.2 실시간 쇼핑순위

설명:

- 네이버 데이터랩 쇼핑인사이트 기반 카테고리 트렌드 순위
- 최근 수집 시각 표시
- 최근 3일 랭킹 제공

확인된 카테고리:

- 가구/인테리어
- 디지털/가전
- 생활/건강
- 스포츠/레저
- 식품
- 여가/생활편의
- 출산/육아
- 패션의류
- 패션잡화
- 화장품/미용

화면 구성:

- 카테고리 버튼
- 최근 3일 날짜별 TOP 10
- 키워드별 검색 버튼
- 돌아가기 버튼

클론 구현 요구:

- 네이버 데이터랩 또는 자체 수집 데이터 소스 연동
- 일별/카테고리별 랭킹 저장
- 키워드 클릭 시 제품 찾기 또는 영상 검색으로 연결
- 수집 시각 표시

### 21.3 신규 쇼핑 영상

설명:

- 관리자가 골라둔 최신 쇼핑 영상을 바로 보고 담아서 제품찾기 메인 소스로 쓰는 화면
- 카드형 목록으로 영상 썸네일, 제목, 채널명, 날짜, 담아간 사람 수, 보기 링크, 담기 버튼을 제공한다.

확인된 구조:

- 제목
- 채널/출처명
- 날짜
- `N명이 담아감`
- 보기 링크
- 담기 버튼

클론 구현 요구:

- `CuratedVideo` 모델 생성
- sourcePlatform, sourceUrl, thumbnailUrl, title, channelName, publishedAt, savedCount 필드
- 보기 버튼은 원본 URL 새 탭 열기
- 담기 버튼은 내 라이브러리 또는 현재 프로젝트 소스로 저장

### 21.4 추천 픽 영상

설명:

- 관리자가 직접 골라둔 영상을 보고 프로젝트에 활용하는 화면
- `게시글` 버튼과 `담기` 또는 `마감` 상태가 있다.
- 일부 콘텐츠는 `마감 (10/10명)`처럼 최대 담기 인원 제한이 있다.

확인된 구조:

- 추천 영상 제목
- 날짜
- `N/10명이 담아감`
- 게시글 버튼
- 담기 버튼
- 마감 disabled 버튼

클론 구현 요구:

- 추천 픽은 제한 수량/선착순 구조를 둔다.
- `capacity`, `savedCount`, `isClosed` 필드를 둔다.
- 담기 성공 시 savedCount 증가와 중복 담기 방지를 원자적으로 처리한다.
- 게시글 버튼은 상세 설명/원본 게시글/상품 정보 모달 또는 페이지로 연결한다.

### 22.2 영상 스타일 분석실

- 벤치마크 영상 URL을 입력하면 다운로드 + 분석에 1~2분 걸릴 수 있다고 안내한다.

클론 구현 요구:

- 영상 길이 제한 검사
- 음성/자막/화면 구조 분석
- 톤, 화자, 말투, 컷 구성, 자막 스타일, 후킹 방식 추출
- 추출 결과를 StyleProfile로 저장
- 직접 지침 추가 기능 제공
- 저장된 프로필 수 표시

클론 구현 요구:

## 24. 포인트/과금 시스템 보강

실제 화면 기준으로 포인트 단위는 `P`를 사용한다. 영상 다운로드는 0.5P 차감이 확인됐고, 실패 시 자동 환불 정책이 있다.

클론 구현 요구:

- `PointLedger` 모델을 반드시 둔다.
- 모든 포인트 변화는 ledger에 기록한다.
- 차감/환불/충전/관리자 조정 타입을 구분한다.
- 비동기 작업 실패 시 자동 환불한다.
- 포인트 차감은 작업 생성과 같은 트랜잭션에서 처리한다.

추천 ledger 필드:

- id
- userId
- type: charge, spend, refund, admin_adjust
- amount
- balanceAfter
- reason
- relatedJobId
- relatedProjectId
- createdAt

## 25. 실제 클론 MVP 우선순위 재정렬

로그인 후 화면을 기준으로 MVP 우선순위를 다시 잡으면 다음 순서가 가장 현실적이다.

1. 인증/세션/보호 라우트

3. 프로젝트 생성 한도와 프로젝트 리스트

5. URL/파일 입력 + 분석 작업 큐
6. 스타일 프로필 라이브러리
7. 음성 프리셋/미리듣기
8. 대본/자막/음성 생성
9. 영상 렌더링 및 내보내기
10. 포인트 ledger와 다운로드 0.5P 과금/환불
11. 신규/추천 영상 큐레이션
12. 네이버 쇼핑순위 수집
13. 영상 스타일 분석실
14. 내 쇼핑 링크 공개 프로필
15. 관리자 큐레이션/회원/포인트 관리
