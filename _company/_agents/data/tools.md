# 📈 Data — 도구 매니페스트

## 자율도 레벨

AUTONOMY_LEVEL: 2

## 사용 가능한 도구

### `csv_profile`
CSV/XLSX 데이터 프로파일링과 품질 이슈 요약.

### `metric_dashboard`
핵심 KPI 대시보드 초안 생성.

### `sql_review`
SQL 쿼리 성능·정확성 리뷰.

### `report_generator`
분석 결과를 CEO/Business용 리포트로 변환.

### `web_research_api`
Tavily/Web Research API를 사용한 읽기 전용 검색·추출.

## 안전 규칙

- 원본 데이터는 덮어쓰지 않습니다.
- 개인정보나 민감 데이터는 보고서에 그대로 복사하지 않습니다.
