# Antigravity Curated Skills

Use these upstream skills as reference patterns when Secretary is handling scheduling, messages, reminders, email triage, or team coordination.

Source repository: https://github.com/sickn33/antigravity-awesome-skills.git

## Primary Matches

- `telegram-automation` - Telegram messaging, chats, documents, and bot commands. Treat as high-risk guidance.
- `outlook-automation` - Outlook email, calendar, contacts, folders, and attachments.
- `outlook-calendar-automation` - calendar events, attendees, meeting times, and schedule management.
- `notion-automation` - Notion pages, databases, blocks, comments, and users.
- `microsoft-teams-automation` - Teams messages, channels, meetings, and chats.

## Operating Rule

Secretary should draft external communications and schedule changes first. Sending, inviting, deleting, or modifying live external data needs explicit approval unless the user has configured a trusted automation flow.
