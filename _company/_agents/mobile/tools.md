# 📲 Mobile — 도구 매니페스트

## 자율도 레벨

AUTONOMY_LEVEL: 2

## 사용 가능한 도구

### `expo_scaffold`
Expo/React Native 앱 골격 생성.

### `mobile_ui_review`
모바일 화면 밀도·터치 타깃·접근성 점검.

### `store_release_pack`
앱스토어/플레이스토어 출시 메타데이터 준비.

### `device_test_plan`
기기별 테스트 매트릭스와 회귀 테스트 계획.

## 안전 규칙

- 앱스토어 제출, 인증서 변경, 배포 트랙 변경은 승인 게이트 필수입니다.
