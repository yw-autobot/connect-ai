# Tavily / Web Research Account

Data and Researcher use this connection for read-only web search, extraction, and research.

Configuration is managed in `tavily_account.json` through **Connect AI: 외부 연결 (API 키)**.

Safety defaults:
- Read-only search is allowed.
- External writes are not part of this tool.

This diagnostic tool only checks whether credentials are present. It does not make a web request.
